# Banana Toss Game

## Описание
Remake классической игры, которая шла в комплекте с QBASIC, где обезьяны перекидываются бананами через здания в городе.

## Особенности
- Ретро-стиль, напоминающий QBASIC
- Физика переброски бананов через здания
- Несколько уровней с растущей сложностью
- Контроль с помощью тач-интерфейса
- Система очков и прогресса

## Технологии
- Unity 3D (2D)
- C#
- Physics2D

## Структура проекта
```
Assets/
├── Scripts/              # Исходный код
│   ├── GameController.cs  # Основной контроллер игры
│   ├── Monkey.cs          # Контроллер обезьяны
│   ├── Banana.cs          # Контроллер банана
│   ├── Building.cs        # Контроллер зданий
│   ├── LevelManager.cs    # Управление уровнями
│   ├── UIManager.cs       # Управление интерфейсом
│   ├── GameMechanics.cs   # Основная игровая логика
│   └── GameSettings.cs    # Настройки игры
├── Scenes/               # Сцены игры
│   └── MainScene.unity    # Главная сцена
├── Prefabs/              # Префабы объектов
├── Sprites/              # Графические ресурсы
└── Audio/                # Аудиоресурсы
```

## Как собрать
1. Откройте проект в Unity 3D
2. Откройте сцену MainScene
3. Нажмите кнопку Play для запуска

## Как играть
- Нажмите на обезьяну, чтобы выбрать её
- Нажмите и удерживайте палец, чтобы выбрать направление броска
- Отпустите, чтобы бросить банан
- Цель - доставить банан в цель через здания

## Разработка
Этот проект создан как ремейк классической игры из комплекта с QBASIC, с сохранением основной механики переброски бананов через препятствия в городе.
