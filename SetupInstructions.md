# Инструкция по настройке проекта Banana Toss Game

## Необходимые компоненты
- Unity 2021.3 LTS или выше
- Visual Studio или Rider для C# кода
- Basic knowledge of Unity 2D development

## Шаги по настройке

### 1. Создание нового проекта Unity
1. Откройте Unity Hub
2. Нажмите "New Project"
3. Выберите шаблон "2D Template"
4. Укажите путь к папке проекта: `D:\DeepSeek Harness\WorkArea\BananaTossGame`
5. Назовите проект: `BananaTossGame`
6. Нажмите "Create"

### 2. Настройка структуры проекта
1. В папке Assets создайте следующие папки:
   - Scripts
   - Scenes
   - Prefabs
   - Sprites
   - Audio

### 3. Импорт скриптов
1. Скопируйте все файлы из папки Scripts в папку `Assets/Scripts` проекта
2. Основные файлы:
   - GameController.cs
   - Monkey.cs
   - Banana.cs
   - Building.cs
   - LevelManager.cs
   - UIManager.cs
   - GameMechanics.cs
   - GameSettings.cs

### 4. Настройка сцены
1. С откройте файл `Assets/Scenes/MainScene.unity`
2. Убедитесь, что есть Main Camera с компонентом Camera
3. Добавьте GameController в сцену (его можно найти в ScriptableObject)

### 5. Настройка физики
1. В меню Window -> Physics 2D Settings
2. Установите параметры гравитации:
   - Gravity: Y = -9.81
3. Убедитесь, что для всех игровых объектов установлены:
   - Collider2D
   - Rigidbody2D (если нужен физический расчет)

## Структура проекта

### Scripts
- **GameController.cs**: Основной контроллер игры
- **Monkey.cs**: Управление обезьянами (бросание бананов)
- **Banana.cs**: Логика движения и взаимодействия бананов
- **Building.cs**: Логика поведения зданий
- **LevelManager.cs**: Управление уровнями
- **UIManager.cs**: Интерфейс пользователя
- **GameMechanics.cs**: Основная игровая логика
- **GameSettings.cs**: Конфигурация игры

## Тестирование
1. Откройте сцену MainScene
2. Нажмите Play для запуска
3. Тестируйте взаимодействие с обезьянами и бананами
4. Проверьте, правильно ли работает физика и коллизии
